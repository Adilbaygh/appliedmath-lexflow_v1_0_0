# Model workspace

Бу папка *AppliedMath* мақоласининг мустақил детерминистик математик моделини сақлайди.

- `MATHEMATICAL_MODEL.md` — machine-readable формулировка;
- `THEOREMS_AND_PROOFS.md` — икки асосий теорема ва королларийлар;
- `IMPLEMENTATION_SPEC.md` — Python solver contract;
- `EXACT_EXPERIMENT_PROTOCOL.md` — аниқ benchmark ва қабул gate’лари;
- `MODEL_CHANGELOG.md` — модель версиялари тарихи;
- `Model_AppliedMath_UZ.docx` — фойдаланувчи учун Word ҳужжат.

Модель фақат аниқ берилган $d$, $Q$, $C$, $\eta$, маршрутлар ва вазнлардан фойдаланади. Унда сценарий, эҳтимол тақсимоти, uncertainty set, робаст counterpart ёки recourse қарорлари мавжуд эмас.
