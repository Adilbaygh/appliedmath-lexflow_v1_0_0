# Model workspace

Бу папка *AppliedMath* мақоласининг мустақил детерминистик математик моделини сақлайди.

- [`MATHEMATICAL_MODEL.md`](MATHEMATICAL_MODEL.md) — machine-readable формулировка;
- [`THEOREMS_AND_PROOFS.md`](THEOREMS_AND_PROOFS.md) — икки асосий теорема ва королларийлар;
- [`IMPLEMENTATION_SPEC.md`](IMPLEMENTATION_SPEC.md) — Python solver contract;
- [`EXACT_EXPERIMENT_PROTOCOL.md`](EXACT_EXPERIMENT_PROTOCOL.md) — аниқ benchmark ва қабул gate’лари;
- [`MODEL_CHANGELOG.md`](MODEL_CHANGELOG.md) — модель версиялари тарихи.

Мақола қораламаси ва журнал шаблони лицензия ва иш жараёни сабабли очиқ
дастурий репозиторийдан ташқарида сақланади.

Модель фақат аниқ берилган $d$, $Q$, $C$, $\eta$, маршрутлар ва вазнлардан фойдаланади. Унда сценарий, эҳтимол тақсимоти, uncertainty set, робаст counterpart ёки recourse қарорлари мавжуд эмас.
